FUNDED BY DESIGN WEBSITE
========================
1. Open index.html to preview.
2. Edit the RESOURCE DATABASE near the bottom.
3. Free product link = direct file/download link.
4. Premium product link = checkout URL from your payment/digital-delivery service.
5. Replace the Instagram URL in the Follow button.
6. Upload the whole folder to GitHub Pages, Netlify, Cloudflare Pages, or another static host.

The resource database lets you keep adding products without changing the page layout.
